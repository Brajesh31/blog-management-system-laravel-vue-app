# 📖 Glossary

| Term | Meaning |
|---|---|
| Laravel | PHP framework for routes, middleware, controllers, validation and responses |
| Inertia.js | Connects Laravel responses to Vue pages without a separate frontend API server |
| Vue 3 | Component framework used in the browser |
| TypeScript | Static typing for frontend code |
| Vite | Development server and production asset bundler |
| Eloquent | Laravel ORM and relationship layer |
| Form Request | Laravel class for request authorization and validation |
| Middleware | Request pipeline layer that can authenticate or verify users |
| Session authentication | Cookie-backed browser authentication managed by Laravel |
| Verified user | Account whose email verification passes Laravel's `verified` middleware |
| Inertia page | Vue component resolved from a server response, for example `Posts/Create` |
| TipTap | Rich-text editor used by the post creation form |
| Sanitization | Transforming rich HTML using an allowlist before rendering |
| CSRF | Cross-site request forgery protection for session-based mutations |
| Slug | URL-friendly text derived from a post title; current route binding still uses primary key |
| Visibility | Post state such as draft/published; DB supports additional states |
| Migration | Versioned schema change in `database/migrations/` |
| Factory | Helper that creates model records for development/testing |
| Seeder | Script for populating data; sample seeder is for disposable environments |
| Queue worker | Process that executes queued jobs |
| WCAG | Web Content Accessibility Guidelines used for accessibility testing |
