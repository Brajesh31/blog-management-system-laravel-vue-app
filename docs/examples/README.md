# 🧪 Development Examples

These examples are for local development and tests only. Use synthetic data and a disposable database.

## Contents
- [Factory usage](factory-usage.md): create test users and posts safely with model factories.
- [Post creation contract](post-creation.md): field-level semantics of the Inertia form submission.

Do not use these examples as public API requests. The application currently uses Laravel web/session routes rather than a standalone REST API.
