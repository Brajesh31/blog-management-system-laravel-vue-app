# 🧭 Architecture Decision Records

No formal ADRs have been accepted yet. Current implementation choices are described in [Architecture](../architecture.md), [Database](../database.md) and [Security review](../security.md).

## Create a decision record

1. Copy [template.md](template.md).
2. Choose the next sequential number, for example `0001-post-visibility-policy.md`.
3. Use Proposed status until the maintainers accept the decision.
4. Describe context, alternatives, trade-offs, security, privacy, accessibility and migration impact.
5. Add the accepted record to this index.

ADRs are append-only in spirit. Supersede an old choice with a new ADR rather than rewriting its historical rationale.
