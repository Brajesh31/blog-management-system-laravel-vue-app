# 💬 Discussion Guidelines

Use repository discussions or issues for constructive, project-related questions and proposals.

## Good discussions
- Describe the user problem and the context.
- Include relevant routes, files, versions and reproducible steps.
- Separate observed behavior from assumptions.
- Be respectful and specific when disagreeing.
- Consider security, privacy and accessibility when discussing user-facing changes.

## Keep sensitive information private
Do not publish credentials, reset links, cookies, production logs, personal details, private post contents or database dumps. Report vulnerabilities through [SECURITY.md](SECURITY.md), never in a public discussion.

## Scope
Use issues for reproducible bugs and actionable feature/documentation requests. Use pull requests for proposed code changes. Review [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) before participating.
