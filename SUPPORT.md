# Support

This is a community project maintained on a best-effort basis. There is no paid support or guaranteed response time.

## Before asking for help

1. Check the [README](README.md) for the current implementation status; some post and social workflows are not complete.
2. Follow [Installation](docs/installation.md) and check [Troubleshooting](docs/troubleshooting.md) and the [FAQ](docs/faq.md).
3. Search the [repository issues](https://github.com/Brajesh31/blog-management-system-laravel-vue-app/issues) for a similar report.

## Report a reproducible problem

Open an issue in the [GitHub repository](https://github.com/Brajesh31/blog-management-system-laravel-vue-app/issues) and include:

- What you expected and what happened instead.
- Exact steps to reproduce the problem, including the route or page involved.
- The relevant commit or branch, PHP and Laravel versions, Node/npm versions, database driver, and browser/operating system when relevant.
- Whether migrations have run and whether the problem occurs in a fresh local setup.
- Sanitized error output or screenshots that do not expose private data.

For feature requests, describe the user need and the expected behavior. Please check the [Roadmap](ROADMAP.md) and current implementation notes first.

## Protect sensitive information

Never include passwords, API keys, `.env` contents, session cookies, database dumps, private uploads, real user details, or unredacted production logs in a public issue. Remove secrets and personal data before sharing a reproduction.

Do not use a public issue to report a security vulnerability. Follow the private process in [SECURITY.md](SECURITY.md). For conduct concerns, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
