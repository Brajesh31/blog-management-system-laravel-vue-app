# 🎨 Visual Assets

This directory contains original repository presentation assets and guidelines for authentic screenshots/demos.

| Directory | Purpose |
|---|---|
| banners/ | Project hero banner for README/social preview |
| logos/ | Simple project mark in SVG format |
| illustrations/ | Feature/workflow illustrations |
| diagrams/ | Rendered architecture visuals; editable source remains in docs/diagrams |
| screenshots/ | Genuine screenshots captured from a running app |
| demos/ | Actual short recordings/GIFs of user journeys |
| charts/ | Charts based on measured project data only |

Use optimized SVG/PNG/WebP assets, meaningful alt text and consistent branding. Never commit personal data, real credentials or private user content in screenshots.
